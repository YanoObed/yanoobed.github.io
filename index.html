About Me

I’m Obadia Yano, a Data Analytics Software Developer working across data analytics, software development, application development, automation, data engineering, and business intelligence. I build data solutions that combine analytics, software, and automation to support practical decision-making.

My work spans the full data lifecycle, from data collection and API integration to data cleaning, transformation, analysis, visualization, reporting, and forecasting. I also develop software applications and automated workflows that connect operational systems with analytical tools.

I work with data from business systems, health information systems, field data collection platforms, databases, APIs, and other structured data sources. My focus is on turning these datasets into reliable pipelines, dashboards, analytical products, and decision-support solutions.
